Introduccion al Diseno Responsivo

El diseño web responsivo permite que una misma página se adapte de forma fluida a distintos tamaños de pantalla, desde teléfonos móviles hasta monitores de escritorio.

Para lograrlo correctamente, es indispensable incluir la etiqueta meta viewport en la cabecera del documento HTML para controlar el escalado inicial.

<meta name="viewport" content="width=device-width, initial-scale=1.0" />
  • Mejora la experiencia de lectura en dispositivos móviles y tabletas.
  • Evita el desplazamiento horizontal innecesario en pantallas pequeñas.
Unidades Relativas

A diferencia de los píxeles fijos, las unidades relativas calculan su tamaño en función de otro valor, como el contenedor padre o el tamaño de fuente raíz.

Usar unidades como porcentajes, rem y vw ayuda a que la tipografía y los bloques de contenido escalen proporcionalmente.

.contenedor { width: 90%; font-size: 1.125rem; }
  • %: Relativo al tamaño del elemento padre.
  • rem: Relativo al tamaño de fuente del elemento raíz html.
Media Queries

Las media queries permiten aplicar reglas CSS únicamente cuando se cumplen ciertas condiciones del dispositivo, como el ancho de la ventana o la orientación.

Se pueden combinar múltiples características de media utilizando operadores lógicos como and.

@media screen and (min-width: 768px) { body { font-size: 18px; } }
  • min-width y max-width evalúan el ancho de la ventana gráfica.
  • orientation detecta si la pantalla está en modo portrait o landscape.
Imagenes Flexibles

Las imágenes con dimensiones fijas pueden desbordar sus contenedores en pantallas estrechas si no se restringe su ancho máximo.

Configurar el ancho máximo al cien por ciento y la altura automática garantiza que la imagen conserve su relación de aspecto original.

img { max-width: 100%; height: auto; display: block; }
  • Evita la distorsión visual al redimensionar la ventana del navegador.
Enfoque Mobile First

El enfoque móvil-prioritario consiste en escribir primero los estilos base pensando en pantallas pequeñas y luego expandir el diseño hacia pantallas más grandes.

Esta metodología utiliza consultas con min-width para agregar columnas, márgenes amplios y barras laterales en tabletas y computadoras de escritorio.

@media (min-width: 1024px) { .grid { display: grid; grid-template-columns: 1fr 3fr; } }
  • Prioriza el contenido esencial y mantiene un CSS más limpio y escalable.
